# Transformation blueprint

Eleven tracks. Each track names one registered evaluation gate.

## Track 01 — Problem framing

- id: "01", title: "Problem framing"
Eval gate: `perimeter_track_count_consistent`

State the problem in the learner's words before any solution work.

## Track 02 — Outcome specification

- id: "02", title: "Outcome specification"
Eval gate: `perimeter_state_delta_valid`

Write the outcome the curriculum and return model must share.

## Track 03 — Discovery interviews

- id: "03", title: "Discovery interviews"
Eval gate: `perimeter_readme_rich_contract`

Interview trainees and managers as two audiences.

## Track 04 — Opportunity sizing

- id: "04", title: "Opportunity sizing"
Eval gate: `perimeter_roi_inputs_parametrised`

Size the opportunity with overridable rate inputs.

## Track 05 — Solution shaping

- id: "05", title: "Solution shaping"
Eval gate: `perimeter_stitch_token_valid`

Shape the interface with the neutral craft tokens.

## Track 06 — Experiment design

- id: "06", title: "Experiment design"
Eval gate: `perimeter_eval_suite_deterministic`

Design checks that return the same result on every run.

## Track 07 — Delivery planning

- id: "07", title: "Delivery planning"
Eval gate: `perimeter_curriculum_dag_acyclic`

Plan delivery across an acyclic track graph.

## Track 08 — Instrumentation

- id: "08", title: "Instrumentation"
Eval gate: `perimeter_ledger_cap_enforced`

Instrument spend so a missing ledger blocks the call.

## Track 09 — Stakeholder narrative

- id: "09", title: "Stakeholder narrative"
Eval gate: `perimeter_docs_diagrams_render`

Tell the story with diagrams that render.

## Track 10 — Launch and adoption

- id: "10", title: "Launch and adoption"
Eval gate: `perimeter_journey_matrix_verified`

Launch the trainee and manager routes.

## Track 11 — Return review

- id: "11", title: "Return review"
Eval gate: `perimeter_roi_monotonic_increasing`

Review the return estimate. It must not fall when an input rises.
